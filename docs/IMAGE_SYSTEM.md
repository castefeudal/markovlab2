# MARKOVLAB 5.0 Image System

## Rule

An image ships only when it explains a measurement, gives a laboratory a navigation motif, or clarifies evidence/privacy/progress. Exact relationships use HTML/SVG/data graphics. Editorial CGI supplies material character only where physical metaphor improves comprehension.

## Master direction

Ivory mineral, graphite, deep forest, controlled mint and restrained brass; precise geometry; quiet studio light; no text inside generated imagery. Prohibited motifs: atom, flask, brain, stock person, floating coin, flame, battery, neon, purple AI gradient and decorative UI mockup.

## Production assets

| Surface | Asset | Meaning | Treatment |
| --- | --- | --- | --- |
| Home | code-native `measure-preview` | input → result → meaning → action | responsive HTML/CSS, screen-reader label |
| Evidence | `evidence-interval-v5.webp` | evidence bounds uncertainty; it does not promise personal precision | 1400×1050, 69.7 KB, eager only on Evidence |
| Profile | `profile-once.webp` | reusable data entered once | supporting, lazy outside Profile |
| Progress | `progress-honest-v4.webp` | observed points without invented smoothing | supporting, lazy |
| Privacy | `privacy-local-v4.webp` plus code diagram | browser → local storage → export | decorative bitmap + explicit accessible text |
| Laboratories | `assets/images/domains/*.webp` | a distinct calibrated physical motif per domain | 4:3, contextual caption |

## Evidence asset selection

Two generated candidates were reviewed. Candidate 2 was selected because the interval is immediately legible, the geometry is calmer and the crop survives desktop/tablet. Candidate 1 had stronger atmosphere but a less explicit range relationship.

## Budgets

- supporting bitmap target: <180 KB;
- rendered dimensions always declared;
- no remote image requests;
- bitmap alt is empty when the adjacent caption carries the meaning;
- diagrams expose a localized accessible label.
