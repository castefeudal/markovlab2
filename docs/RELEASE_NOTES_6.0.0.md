# RELEASE NOTES — MARKOVLAB 6.0.0

Дата: 2026-09-03 · Ветка: `work/markovlab2-ultimate-production` → `main`

## Почему 6.0

Смена namespace хранения и кэшей при разделении форка — breaking-изменение модели данных: приложение больше не читает и не пишет `markovlab-*`. Версия отражает это, а не объём фич.

## Fork isolation

- Новые namespace: `markovlab2-state-v4`, `markovlab2-draft-*`, `markovlab2-active-workflow-v1`, кэш `markovlab2-v6.0.0-r1`.
- Старые данные `/markovlab/` не читаются, не перезаписываются и не удаляются; очистка данных затрагивает только новое пространство.
- Все customer-facing URL переведены на `https://castefeudal.github.io/markovlab2/`.
- Экспорт помечен `app: "markovlab2"`; импорт старых экспортов поддержан.

## Новые калькуляторы (11)

- Энергия: Katch–McArdle (RMR по безжировой массе), пересмотренный Harris–Benedict (Roza & Shizgal 1984), сравнение методов RMR с разбросом оценок.
- Питание: планировщик макросов с проверкой выполнимости (явное сообщение, когда белок+жир не влезают в калорийность).
- Сила: план разминки под рабочий вес (эвристика 40/60/80/90% с округлением до 2,5 кг); оценка 1ПМ расширена до диапазона из четырёх формул (Epley, Brzycki, Lombardi, O'Conner) с медианой и разбросом.
- Кардио: таблица отрезков по дистанции и целевому времени (темп, скорость, накопленные отрезки).
- Финансы: NPV с таблицей дисконтированных потоков, IRR с поиском всех корней и предупреждением о множественных IRR, амортизация кредита (платёж, всего выплачено, всего процентов), точка безубыточности с честной обработкой неположительной маржи, покупательная способность при инфляции.

## Исправленные дефекты

- Формат времени: `pace`, `race-time` и связанные калькуляторы показывали повреждённые значения («0:300», «0:3000»); теперь корректные «м:сс».
- Version drift: пакет 5.4.0, README 5.3, разные ревизии кэша → единый 6.0.0 во всех источниках, проверяется автотестом.
- URL drift: метаданные указывали на старый репозиторий → `markovlab2`.

## Инфраструктура

- CI/деплой: убран бессмысленный `npm install` (ноль зависимостей), добавлены gate'ы изоляции форка и URL-drift.
- Счётчики «86 инструментов» в интерфейсе и тестах стали динамическими.
- Документация: обновлены README, матрицы полноты 97/97, добавлены `FORK_ISOLATION.md`, настоящий QA-отчёт и эти release notes.
