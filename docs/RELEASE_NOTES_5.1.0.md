# MARKOVLAB 5.1.0 — Applied Intelligence

## Главное

- Существенно повышены контраст и минимальный размер содержательного текста.
- Добавлена тёплая тема Paper; четыре визуальные палитры теперь действительно различаются, а System явно обозначен как автоматический режим.
- Создана авторская серия из десяти editorial-фотосцен: отдельные смысловые кадры для всех девяти лабораторий и сценарного анализа.
- Home и все девять лабораторий получили реальные сценарии применения.
- Добавлена прямая речь Павла Маркова на Home и About.
- Все 86 калькуляторов получили Basic / Pro interface.
- Pro позволяет выполнить sensitivity stress test по числовому входу и сравнить Scenario A/B без изменения исходной формы.
- Значения с десятичной запятой нормализуются перед расчётом.
- Новые assets добавлены в offline cache.

## Принцип Pro

Pro не изменяет исходную формулу и не создаёт дополнительные коэффициенты без основания. Он добавляет протокол, технические ограничения и проверку чувствительности результата к выбранному входу.
