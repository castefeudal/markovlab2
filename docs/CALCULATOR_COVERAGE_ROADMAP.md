# Calculator coverage roadmap

MARKOVLAB does not treat “every imaginable calculator” as a quality metric. New tools enter only when a concrete decision, canonical units, formula provenance, validation domain, edge vectors, RU/EN copy, limitation, action, search aliases, related workflow, history/export support and accessibility evidence are present.

## Wave A — highest practical return

1. Body / energy: Katch–McArdle RMR, revised Harris–Benedict comparison, 14–28 day TDEE calibration and a macro planner with feasibility validation.
2. Strength: multi-formula 1RM range, RPE/RIR load table, warm-up planner and the completed inventory-aware plate loader.
3. Cardio: split table, critical speed from multiple trials, swim pace and named heart-rate-zone methods.
4. Finance: NPV, IRR, mortgage amortization, inflation purchasing power, emergency-fund scenarios and break-even / contribution margin.
5. Project work: PERT, capacity, cycle time, throughput and a weighted-priority model with user-controlled weights.

## Exclusions without an independent high-stakes review

- dosing, insulin, hormones, diagnosis or individual disease-risk calculators;
- pregnancy, paediatric or clinical decision tools;
- fake “ideal” bodies, AI health scores or false individual precision.

Each wave is a separate reviewable PR. Catalogue breadth never precedes correctness, provenance and real-browser behavioural evidence.
